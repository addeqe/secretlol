# Coop webshop adapter: verified source and limits

Checked 8 October 2026 through bounded public-webshop probes for online pickup-store pricing. Full catalogue completeness and the GitHub/Worker runtime remain to be verified.

The Coop page exposes its ecommerce and personalization API base URLs and public browser subscription headers in inline settings. The adapter accepts the configured key without copying it into source code. Current page settings used the same key for both services.

## Supported source calls

| Operation | Request | Result and limitation |
|---|---|---|
| Pickup-store search | `GET /pointofservices?query={postalCode}&fields=FULL&api-version=v1` | A read-only query for `11455` returned 20 stores on page 0 and 176 total nearby results. The adapter returns pickup-capable stores from that first page. Delivery store lookup remains unverified. |
| Category tree | `GET /ecommerce/coop/users/anonymous/categories/tree/{storeId}?api-version=v1` | The response wraps recursive `code`/`name` category nodes in `{ nodes: [...] }`. A live tree for store `251300` included category `21330` (`Skafferi`). |
| Category products | Personalization `POST /search/entities/by-attribute?api-version=v1&store={storeId}&groups=CUSTOMER_PRIVATE&device=desktop&direct=false` | The observed category page sends `attribute: { name: "categoryIds", value: "{categoryId}" }` and `resultsOptions` with `skip`, `take`, sort, and brand/environment/top-category facets. A request for category `21330` at store `251300` returned 1,931 results. A second request with `skip: 24, take: 1` returned a different product. The adapter pages this route and associates returned prices with the requested pickup store. |
| Product lookup and price | Personalization `POST /search/entities/by-id?api-version=v1&store={storeId}&groups=CUSTOMER_PRIVATE&device=desktop&direct=false&quickSearch=false` | The frontend sends an array of Coop product IDs. Responses include B2C ordinary and promotion prices, `onlinePromotions`, deposit, package, category and `availableOnline` fields. The same product ID at stores `251300` and `035000` returned ordinary public prices of 32.95 and 35.95 SEK, respectively, and an online promotion price of 25 SEK at both stores. A 10-pack Coca-Cola response reported 3,300 ml package contents and 10 SEK deposit. These checks verify store-specific online prices for those two stores, not delivery-slot pricing. |
| Keyword search | Personalization `POST /search/products?api-version=v1&store={storeId}&groups=CUSTOMER_PRIVATE&device=desktop&direct=false&searchService={optional}` | The first-party client sends `{ query, resultsOptions: { skip, take, sortBy?, facets?, filter? }, relatedResultsOptions }`. A bounded `havre` query returned 168 results. An empty query returned no response body, so category listings use the dedicated by-attribute route above. |

The product lookup's store parameter is part of Coop's first-party request and changes returned public pricing. Source observations expire after at most 24 hours, or at the selected offer's `validUntil` when that is earlier. Local price resolution separately limits its reusable cache to 30 minutes. The request does not carry a delivery channel or slot, so the adapter accepts price requests only for pickup scope without a slot. The `/pointofservices` selector returns pickup-capable stores; it does not establish delivery availability. One product ID was checked at two stores, which does not establish universal cross-store ID portability.

The live tree for store `035000` included two unnamed, empty root entries (`0001` and `0002`, both `/varor/`). The adapter filters only these exact observed placeholders. That tree also repeats category code `334819` under two different parents. Collection now validates every category occurrence and fetches each distinct leaf once; cycles and conflicting category definitions remain errors.

A final smoke test called the actual `CoopClient` through its paced transport for verified pickup store `035000` (Coop Daglivs). Four requests returned 22 category roots, three exact-ID products and two pages of 24 Skafferi products. The category reported 1,836 products, both pages reported the same total, their IDs were distinct, and cursors advanced to 24 and 48. Hönö had a public 25 SEK pack price, butter used its ordinary 61.95 SEK pack price, and Coca-Cola had a 75.67 SEK pack price plus 10 SEK deposit. The probe did not scan all products or contact Cloudflare. Its ignored local evidence is `data/research/retailers/verification/coop-adapter-smoke.json`.

## Price and product mapping

The adapter parses EAN, brand, package quantity and unit, ingredient text, SEK to integer öre, deposit, online availability, and offer dates. Shopper price basis follows Coop's explicit `salesUnit`: `Styck` products use `piecePriceData` and basis `pack`; `Vikt` or `kg` products use `salesPriceData` and basis `kg`. `comparativePriceUnit` describes the separate comparison price and does not change the shopper's selling basis. For example, the tortilla 8-pack is 14.95 SEK per pack despite a kg comparison unit, the oat drink is 15.95 SEK per pack despite a litre comparison unit, and the banana response explicitly says `salesUnit: "Vikt"` with a 21.90 SEK/kg price and approximate 180 g piece weight. Public single-item fixed-price offers use Coop's matching piece or weight price field; member-only, multi-buy, and ambiguous offers fall back to the ordinary public price. Availability comes from `availableOnline` in the store-scoped response; it does not claim a delivery-slot reservation.

`tests/fixtures/retailers/coop-personalization.json` contains scrubbed examples of the observed category, product, and offer fields. The category-tree fixture includes the two observed empty placeholders; its category-page response contains one sample item and tests mapping/cursor shape only, not that a 24-item page is complete. Other Coop fixtures remain synthetic. Tests use an injected local transport and do not access the network.

The adapter does not perform full catalogue scans, Cloudflare requests, or deployments. Coop's webshop remains an unofficial source interface and may change without notice.
